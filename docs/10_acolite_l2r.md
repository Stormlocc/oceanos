# L2R y reprocesamiento

El usuario necesita conservar reflectancias para producir variables adicionales. La selección exacta de L2R persistente se definirá después de inspeccionar datasets, geometría, auxiliares, atributos y dependencias de L2W.

Antes de descargar una escena para generar otro producto, consultar el catálogo local: localizar un resultado compatible, comprobar variables/bandas, corrección, máscaras, grilla y versión. Si contiene lo necesario, ejecutar únicamente la derivación nativa de ACOLITE que corresponda. Registrar una ejecución hija vinculada al resultado fuente.

Si faltan datos o cambian supuestos atmosféricos, adquirir la fuente y reprocesar. No asumir que L2R permite repetir cualquier corrección atmosférica.

Comparar conservación de L2R nativo más L2W proyectado frente a L2R/L2W ambos proyectados. No decidir eliminar L2R por ahorro de espacio antes de resolver la reutilización.
